# Board Demo Script - OHG Studio Builder

**Time:** 5-7 minutes
**Goal:** Demonstrate professional design + functionality
**Key Message:** Production-ready platform with industry-leading design

---

## 🎬 Demo Flow (5 Minutes)

### 1. Opening (30 seconds)
**Action:** Open browser to localhost or deployed URL

**Script:**
> "I'm excited to show you the Office Hours Global Studio Builder—a professional platform for designing studio equipment configurations. Notice the clean, modern interface that immediately communicates the OHG brand."

**Point Out:**
- Orange gradient logo badge (top left)
- "By Office Hours Global" tagline
- Premium dark theme with ambient lighting effects
- Real-time budget display (top right)

---

### 2. Budget Tier Selection (60 seconds)
**Action:** Click through budget tiers ($500 → $5,000 → $10,000 → $20,000)

**Script:**
> "Users start by selecting their budget tier—from $500 starter setups to $20,000 broadcast studios. Watch the smooth transitions and gradient effects that give this a premium feel."

**Point Out:**
- Orange gradient when selected (matches OHG brand)
- Smooth scale animation on hover
- Clear pricing hierarchy
- Pulsing glow effect on active selection

**Demo Tip:** Hover over unselected tiers to show the hover state

---

### 3. Use Case Selection (60 seconds)
**Action:** Click through use cases (Podcasting → Recording → Live → Hybrid)

**Script:**
> "Next, users choose their primary use case. Each production type has a dedicated configuration optimized for that workflow."

**Point Out:**
- Icon-first design (easy to scan)
- Blue/cyan gradient for selected state
- Different equipment lists for each use case
- "Hybrid" option for multi-purpose studios

**Demo Tip:** Show how the equipment list changes when switching use cases

---

### 4. Build Configuration Display (90 seconds)
**Action:** Scroll through the equipment list

**Script:**
> "Here's where the magic happens. The system recommends specific equipment based on the tier and use case, with real prices and explanations."

**Point Out:**
- **Build Info Card:** "Pro Podcast Studio - Multi-source recording setup"
- **Equipment Categories:** Camera, Audio, Lighting, Control, etc.
- **Item Cards:**
  - Gradient price display (orange to match brand)
  - "Mentioned in 3 episodes" badges (links to OHG content)
  - Clear product names and rationale
- **Rack View Button:** Toggle to visual rack diagram

**Demo Tip:** Click "Rack View" to show alternative visualization

---

### 5. Budget Tracking Sidebar (60 seconds)
**Action:** Point to right sidebar, hover over action buttons

**Script:**
> "The budget summary provides real-time tracking with executive-level clarity. Notice how we use color-coding for immediate status recognition."

**Point Out:**
- **Total Spend:** Orange gradient (current: $4,987)
- **Budget:** Blue gradient (tier: $5,000)
- **Remaining:** Green/yellow/red based on status
- **Progress Bar:** Gradient fill with percentage
- **Action Buttons:**
  - Save Build (blue gradient)
  - Share Build (slate)
  - Export PDF (orange gradient)

**Demo Tip:** Hover over buttons to show the scale effect

---

### 6. Closing & Value Proposition (60 seconds)

**Script:**
> "This isn't just a prototype—it's a production-ready platform with design quality that matches industry leaders. Compare this to Sweetwater's studio designer or Waves' StudioRack, and you'll see we're competing at a higher visual standard.

> The design system is built to scale. We can white-label this for partners, integrate it into the OHG platform, or offer it as a standalone SaaS product. The technical foundation is solid: Next.js 16, 2-second build times, fully responsive, and accessibility-compliant.

> Most importantly, every design decision reinforces the Office Hours Global brand. The orange accents, the professional polish, the episode integration—this is clearly an OHG product."

**Point Out:**
- Build succeeded in 2.2 seconds
- TypeScript type-safe
- Responsive design (works on tablet/mobile)
- WCAG AA accessibility compliant
- Office Hours Global branding throughout

## 🚀 Demo Tips

### Before Demo
- [ ] Clear browser cache
- [ ] Close all other tabs/apps
- [ ] Set browser zoom to 100%
- [ ] Test on projector/screen (if presenting in person)
- [ ] Have backup screenshots ready

### During Demo
- **Pace:** Slow down—let people absorb the visuals
- **Pause:** After each section, ask "Any questions?"
- **Pointer:** Use mouse to highlight specific elements
- **Energy:** Enthusiasm is contagious—show you're proud of this

### After Demo
- **Next Steps:** "We'd like approval to launch a beta test with 100 community members"
- **Metrics:** "We'll track engagement, build saves, and click-throughs to affiliate links"
- **Timeline:** "Updates at next board meeting with actual revenue data"
